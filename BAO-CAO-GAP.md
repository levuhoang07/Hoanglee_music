# Báo cáo gap

## Gap hiện tại

| Gap | Ảnh hưởng | Cách xử lý |
|---|---|---|
| Chưa có thiết kế UI cuối | Có thể phải sửa giao diện | Dùng prototype trước, chốt style sau |
| Chưa có Google Cloud project | Chưa test được Drive thật | Tạo project trong pilot |
| Chưa có domain | Chưa cấu hình OAuth domain production | Dùng localhost trước |
| Chưa có file nhạc test chuẩn | Khó test nhiều định dạng | Chuẩn bị file MP3, WAV, M4A, OGG hợp lệ |
| Chưa có quyết định hosting | Chưa public được | Chọn Vercel hoặc Netlify trong pilot |

## Gap không chặn MVP local

Các gap trên không chặn build MVP local. Chúng chỉ chặn public hoặc tích hợp Drive production.
